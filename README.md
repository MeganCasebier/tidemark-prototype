# Tidemark: a working prototype

Tidemark is a small-business lender that doesn't exist. Its payment-exceptions screen has been
stuck in review for a month: nobody owns the call on who resolves a short-paid loan. This is the
prototype that gets the call made. It has one row per loan in trouble, every payment attempt under
it, four states derived from the payments, and one button that knows the next step.

Open `index.html` in a browser. There's no build step and no dependencies: one HTML file, one
stylesheet, and one script.

**Provenance.** Built by Megan Casebier as a portfolio piece; it runs on the homepage of
[megancasebier.com](https://megancasebier.com/). Every business, loan, ID and amount is fictional
fixture data, written for this prototype. No real company, customer or employer material is in it.
